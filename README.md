# 🎥 BuzzTube

BuzzTube is a modern YouTube-inspired video streaming web application built using Next.js, TypeScript, Redux Toolkit, and Tailwind CSS. The project provides a responsive and interactive user interface for browsing videos, searching content, watching videos, and exploring comments.

This project demonstrates frontend architecture, API integration, dynamic routing, state management, and responsive UI development using modern web technologies.

# 🧠 Application Workflow

1. User lands on the homepage
2. Videos are fetched and displayed dynamically
3. Users can search videos using the search bar
4. Search suggestions appear dynamically
5. Clicking a video opens the Watch Page
6. Video playback and comments are displayed
